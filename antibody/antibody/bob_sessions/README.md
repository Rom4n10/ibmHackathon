# Bob task session summaries

Evidence of IBM Bob usage required by the hackathon. Every team member adds
the task session summary screenshot of each Bob task related to this project.

**How to capture:** Bob IDE chat > **Tasks** > open the task (select **All** if
it ran in another workspace) > select the task header > screenshot the session
consumption summary as PNG.

**File name:** `<team>_task<NN>_<short-description>.png`,
for example `antibody_task07_vaccine_round2_summary.png`.
